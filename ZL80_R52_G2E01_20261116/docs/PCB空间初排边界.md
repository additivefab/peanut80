# PCB空间初排不是布线优化

空间初排未将每一个反馈、去耦网络闭合为可制造布局。尤其B06/B07原18×20mm板框与TO18二极管、接插件、安装孔存在空间竞争，部分反馈/去耦件仍需重排。`engineering/layout_priority_review.csv`列出其与相关IC的中心距离，不能把这个距离当作真实走线长度。

在原生KiCad中优先放置求和节点、Rf/Cf、运放与去耦，之后再布置阈值、接插件和测试点。必要时经G1接口变更扩大板框、调整支架或采用双面装配，不能为了维持旧板框把高阻反馈走成长环路。

目前STEP只证明给定占位几何可以生成；没有验证螺钉头、垫圈、扳手/插拔空间、实际引脚高度、焊接工艺、真实铜回路或电磁兼容。图示高度为暂定占位值。
