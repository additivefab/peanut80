## 固定架构

80 mm有效幅宽；100 mm横扫预留；实体顶部狭缝104×1.2 mm。激光→准直/ND/参考取光→反射式旋转多面棱镜→f-theta→连续运动胶片→横置积分筒→径向侧窗→PMMA导光件→单PMT→模拟前端→DC耦合ADC→FPGA。圆筒轴X，片进给Y，Z向上，两端封闭。

首版模拟前端按新PPT采用线性TIA。原机LOG作为互斥的替换卡路线保留，不能把两者并接PMT。未设计普通相机、整线照明加单PMT或振镜替代路线。

## 本版关键改进

- 不只画板框：8块定制PCB草稿＋SP2托板定义了坐标、孔位、层数目标、上下器件高度、维护方向；84个关键器件或功能空间区域参与布置。
- PMT候选为H10720-20针脚式模块；8×10 mm入口导光件在输出端收至5.2 mm方形，针对φ8 mm有效光阴极重新起算。几何可容纳不代表导光效率已验证。
- PMT插座和短输入前端靠近布置；模拟舱、采集舱、驱动和开关电源分区；SP2接口按V1.3B并明确1.8/3.3/5V边界。
- 四辊连续走片，牵引与计量独立；SOS/EOS、参考PD、入出片、温度、开盖/失扫、可选馈片异常均在表格/图中定义位置及接口。
- 纳入插拔、线束、维护空间；关键器件突出空间与刚性核心复核；不把裸板能放入当成已完成整机装联。

## 本次已执行检查

73个名义CAD形体有效，核心刚性件未发现体积重叠；关键器件空间盒与核心件复核无未解决碰撞（PMT插针/插座等预期接合单独标记）。35项计算和参考数据链测试通过。PDF最终渲染和Excel公式已检查。

这些检查**不代表**真实光学、PMT线性、高OD信噪比、胶片无划伤、EMC/安全或寿命已经合格。没有运行KiCad原生ERC/DRC，也没有完成RTL综合与时序验证。

## 明确未关闭的设计事项

关键光学器件需联合RFQ并锁定真实处方、工作距离和全视场光斑；SP2的110×60×25 mm仅保守安装限界，孔距/接口位置需实测；编码器量化步距不代表真实走片精度。B03/B04/B05等FUNCTION_ONLY区域需完成器件级电路、外围、焊盘、保护和完整PCB布线；全紧固、公差链、线束弯曲、装配工艺仍需深化。**本包不提供Gerber，不应按此直接下单生产。**

本版主机安装包络320×300×300 mm，不含外置卷架/馈片器。基座与铝外罩名义质量已约4.33 kg，整机试制预算6–8 kg待称重；**早期≤3.5 kg便携目标尚未实现**。优先验证核心链路后再进行减重和小型化，而非用缩小的占位盒宣称目标已达成。
