## ZL80 扫描光学头联合询价书

RFQ-G1-001 / R52-G01-D01 / 2026-11-16 / 技术答复优先于报价

> 询价对象：635nm激光/整形、六面polygon及驱动、单轴f-theta镜头、同步探测与安全快门。未授权按包络生产转子；报价不构成设计冻结。

用途：80mm有效幅宽工业底片飞点透射扫描，横向保留100mm光学范围，胶片连续直通。单PMT收光在胶片之后，通过横置狭缝积分筒径向侧窗耦合。非激光加工、非相机、非二维振镜。[U01/U02]

| 输入项 | 当前目标与允许答复 |
|---|---|
| 波长 | 635nm名义；请注明实际公差、温漂与光谱。 |
| 有效/预留幅宽 | 有效80mm，物理扫描100mm；SOS/EOS目标投影±46mm。 |
| 扫描器 | 六面候选；请给所选总成的额定及最低稳定rpm，不以产品族范围代替。 |
| 预算转速 | 300、600、1200、3000rpm四点，请逐点答复适用性、误差与温升。 |
| 光束 | 束径4/5/6mm、M2=1.3仅算例；请提供实际束腰位置、椭圆率及可配整形。 |
| 焦距/光斑 | EFL100仅起点；有效场1/e2直径≤35um、CRA≤5deg均为待批准目标。 |
| 空间 | 旧镜组96×44×30mm、总成70×70×65mm仅旧预算，可提出有依据的修改。 |
| 关键风险 | 本包R20/5mm正六边形算例场边截光；请提供真实镜面口径/光束足迹解决方案。 |

请勿只答“能扫100mm”或“中心光斑满足”。需对整条光学链、所有facet、场边与真实安装位置给出证据。

## RFQ 评审与交付接受条件

### 分开评审技术与商务

首先审查技术可行性、真实模型与接口，之后比较交期、价格、MOQ、NRE、质保和第二来源。供应商修改焦距、镜面口径、束径、工作距离或总成外形必须作为偏离项提交。

| 接受条件 | 提供的证据 |
|---|---|
| 身份与版本 | 确定型号/版本/序列号范围；STEP、光学模型、数据表与测试报告对应同一配置。 |
| 几何匹配 | 真实镜面和镜头模型下全场通光；工作距离/入瞳/装调位置自洽。 |
| 性能条件 | 各rpm、各facet、全有效场实测或可信模型；明确仿真与实测区别。 |
| 可重复性 | 冷热状态和重复装夹条件；系统测量误差及仪器校准信息。 |
| 同步/安全 | INDEX/LOCK/FAULT和SOS/EOS电气合同；故障禁能逻辑与外壳防护责任。 |
| 未满足项 | 列出代价、残余风险、建议试验；没有证据的项不视为符合。 |

### 厂家答复附件清单

请附正式数据表、机械图、STEP、镜头处方/黑盒、field结果CSV、原始测试记录、主轴驱动接口说明、波形、安装/安全说明及商务报价。知识产权限制可用授权黑盒替代开放处方，但必须允许约定条件的性能复核。
