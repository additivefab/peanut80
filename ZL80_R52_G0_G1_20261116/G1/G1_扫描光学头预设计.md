## G1 扫描光学头预设计

ZL80 R5.2 / 635 nm + polygon + f-theta / R52-G01-D01

> 当前交付：可追溯预设计、计算、接口CAD、RFQ与PoC方案。缺少真实镜头处方和台架数据，G1不得标为完成验证。

光学链固定为：635 nm激光 → 准直/整形 → ND与参考取光 → 失电关闭快门 → 旋转多面反射镜 → f-theta镜头 → 连续走片的胶片 → 矩形狭缝积分筒 → 径向侧窗 → PMMA → 单PMT。[U01/U02/U03]

### 01 本包实现边界

提供有限尺寸六面镜的主光线反射、镜面足迹筛查和理想角度到位置映射。没有虚构f-theta镜片曲率、玻璃材料、镀膜、像差或Zemax工程；真实模型须由RFQ取得后导入专业光学软件。

CAD中激光、棱镜、主轴、快门和镜头为原有采购包络；外壳和精密转子不能据此加工。射线迹线只画到镜头参考入口，输出焦点仅为理想目标标记。

## G1 扫描几何与正确的时序预算

### 02 核心计算关系

令N为面数、r为rpm、f为理想f-theta有效焦距(mm)、W为有效幅宽(mm)、p为采样间距(mm)。在每个镜面产生一条有效轨迹的假设下：

f_line = N*r/60 ; omega = 2*pi*r/60 ; v_x = 2*f*omega

t_ROI = W/v_x ; dwell = p_x/v_x ; v_y = p_y*f_line

instant_pixel_rate = v_x/p_x ; average_pixel_rate = (W/p_x)*f_line

| 6面 / 3000 rpm / EFL100 / 50um | 本次计算值 |
|---|---|
| 理论物理行频 / 每面周期 | 300 Hz / 3.333333 ms |
| 横向扫描速度 | 62,831.853 mm/s |
| 100mm扫幅 / 92mm同步 / 80mm ROI时间 | 1.591549 / 1.464225 / 1.273240 ms |
| 光学半角 / 机械半角 | ±28.647890 deg / ±14.323945 deg |
| 50um像素驻留 / 瞬时像素率 | 0.795775 us / 1.256637 MHz |
| 平均输出像素率 / ROI占空比 | 0.480000 Mpixel/s / 38.1972% |
| 进片速度 / ROI内走片距离 | 15 mm/s / 19.098593 um |
| 20MSPS采样 / 16bit双通道Raw流 | 约15.915样本/50um像素 / 80 MB/s（不含标签） |

> 0.48 Mpixel/s是整行平均输出，不能作为有效横扫期间的采样或带宽预算。减慢Y进片而不减慢polygon，不会延长单次横扫的像素驻留。

300/600/1200/3000 rpm和25/50/100 um场景已输出scan_modes.csv；所有低速点都必须经选定主轴型号验证。这里没有假设任意polygon均支持300 rpm。[V02]

### 04 如何使用敏感性表

polygon_aperture_sensitivity.csv比较20/22/24/26/30 mm外接半径与4/5/6 mm束径。另列99%高斯径向轮廓投影的保守边缘筛查；它不是精确的整束截光积分，更不是系统透过率。

允许的处理路径是增大有效镜面、减小入射束径、改变光路入射几何或调整镜头方案。任何处理都牵连光斑、入瞳、机架及风险，应由供应商联合答复。本包没有静默把40 mm转子改成另一规格，也没有将当前模型判为合格。

> 自动测试“PASS”表示程序正确暴露了负余量，不表示镜面口径设计已通过。风险R01保持OPEN。

## G1 镜头、光斑与真实模型接入

### 05 理想模型能说明什么

以635 nm、M2=1.3、EFL100 mm、入射高斯束1/e2直径5 mm计算，理想无像差束腰直径约21.02 um；FWHM约12.38 um。此估算仅用于束径/焦距敏感性，不证明全场光斑、离焦性能或真实分辨率。[D01]

d_1e2 = 4*M2*lambda*f / (pi*D_beam)

ideal_mtf_budget_NOT_LENS_PERFORMANCE.csv给出假定高斯点扩散函数的解析MTF，以及附加50 um矩形积分窗的理论曲线。未包含像差、镜面抖动、走片误差、胶片颗粒、AFE响应和重采样；不能作为产品MTF报告。

### 06 供应商必须提交

| 项目 | 最低答复 |

| 实际场覆盖 | 635nm、六面polygon真实主轴/镜面位置下，100mm物理场及80mm有效场。 |

## G1 SOS/EOS与逐面同步

### 07 光学窗口先于图像窗口

以SOS为0时刻：ROI起点约95.493 us，ROI终点约1368.733 us，EOS约1464.225 us。100mm物理扫描区从约-63.662 us延续至1527.887 us。前后保护时间还须叠加激光建立时间、主轴相位误差和接收恢复时间，不能据本算例直接写死硬件门控。

图见 drawings/ZL80_G0_G1_接口与时序图册.pdf。

### 08 面号、失锁与恢复

只有等间隔SOS/EOS而没有每转一次的参考时，不能可靠保持物理facet绝对编号。应要求主轴INDEX/Z或等效可验证相位；启动、丢脉冲或掉电后先令facet_valid=0，不得盲用旧逐面LUT。

初始同步获取必须有受控状态机：先确认封闭互锁、驱动锁速和故障清除；经安全评审允许有限的低功率同步搜索；规定时间未获得有效同步则禁能。不能要求“已有SOS才允许第一次出光”，也不能因搜索同步而绕过防护。

### 10 G1电子文件的边界

G1提供ICD逻辑接口、时序和测试要求，不交付“已闭合”的B06/B07/B08原理图或PCB。S5971只是候选光电二极管，跨阻级、比较器、阈值、ESD、供电/电平和引脚均需G4设计审查。

本版没有复用未经确认的SP2引脚约束进行上板。G4/G5必须核对实物版本、Bank电压、AD9268模式、时钟和SPI后再形成最终XDC及电气图。

CAD导入程序执行结果与真实干涉检查必须区分：当前通过的是STEP形体有效性，不是运动包络、线束、拆装或公差检查。
