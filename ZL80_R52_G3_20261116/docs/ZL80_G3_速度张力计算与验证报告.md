### 禁止把三种力混用

### 必须补的模型输入

真实湿度/污染下静动摩擦、加载有效径、上辊移动质量、预载不平衡、启动轴承阻力、弹簧散差、真实惯量、速度转矩曲线、底片抗划伤上限。保持转矩与需求的比值不作为PASS。

摩擦敏感性表覆盖μ=0.15/0.3/0.5、法向力2/4.1/6N及设计拉力多档，仅作设计筛选。若滑移出现，应停机记录，不用图像插值修复后宣称机械通过。

## V2 夹紧、牵引与转矩预算

| 通道/器具 | 最低记录要求 |
|---|---|
| 独立位移参考 | 不能用被评估编码器或STEP脉冲作真值；记录量程、校准、分辨率、带宽和不确定度 |
| 编码器A/B/Z | 同时采入口/出口轴；登记PPR、倍频、方向、轮径标定、角周期修正表 |
| 张力 | 标定0~5N量程候选；注明受力位置/包角/安装，不把压辊法向测力当张力 |
| 时间 | 同一时间基准或有已知误差的同步；建议1kHz开始，并声明抗混叠与实际采样间隔 |
| 样片/环境 | FilmID、厚度、宽度、批次、前后面、温湿度、清洁/已用次数 |
| 驱动 | B05版本、电流、细分、供电、实际棱镜/辊速、加速度、热机时间 |
| 安全 | 先无光、无贵重原片；核对禁能、开盖/提辊互锁、夹点和回退方案 |

每一速度至少3次独立装片。加速段与稳态段分别保存；用于分析的稳定窗口在试验前定义。低速0.5mm/s至少10s只有5mm样程，不能据此证明1m尺度或全辊周精度，长片和全周试验另做。

若报告5μm级RMS，应使参考仪器不确定度对目标有足够区分能力，并公开仪器带宽、滤波、时钟误差和空间对准。不可靠任意平滑、重新对齐或缩短窗口获得好看的数字。
