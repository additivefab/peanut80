## 本版关键决定
1. 近立式片仓，80°为0.20mm片厚算例起点；50张和80×300是用户要求，厚度/力/尺寸未实测。
2. 剥离前张 + 限矩反向辊。托趾与剥离靴必须先做透明样机，不能用单张厚度硬缝控制张数。
3. 除静电作用于暴露面和层间开口；胶片绝缘不能只靠机壳接地。商业离子器、气源和通风按厂家要求。
4. 300mm整张完全通过双张站再扫描。名义Y=-390检测站到Y=-35停片前沿355mm，包含停止预算。
5. 原四辊需入口/出口主动接管，解决首尾尚未同时夹持的问题。所有馈片和缓冲压辊在扫描前释放。
6. 文件已持久保存 + 实物收片确认才累计1张。双张/未知数量不得静默跳过；最多2次安全自动重试，失败暂停。
7. B10控制板110×80mm只是空间/接口起点；G2还需完整器件级电路，G3还需布线/叠层/回流/ERC/DRC/回装。

## 未关闭项目
实际胶片厚度/质量/乳剂/摩擦/静电；托趾与前张剥离可制造机制；紧贴双张/错边检测；驱动/离合/传感器型号；安装公差与完整CAD；B10电路/PCB；气源/臭氧/EMI/安全；实机批次可靠性。无Gerber、无新生产STEP、无硬件测试报告。

尤其注意：50张0.35mm厚片在80°时自然法向载荷约1.00N，高于示例0.9N目标。必须换角度/卸载机构或经过验证的力配方，不能靠“恒力弹簧”忽略这个约束。Excel中负的附加压板余量是有意的不可行性提示。

运行空间暂留约350×1100×550mm，含完整确认缓冲与收片盘；不声称能装回旧320×300×300mm包络。一体化表示共同机座/遮光/控制/任务与安全接口，不等于所有附件都塞在旧罩内。

本包只交付本次新增ADF设计，不代替或证明历史R5.2完整光机电文件。原积分筒—亚克力收光—PMT链路保持，不在本次重选。
