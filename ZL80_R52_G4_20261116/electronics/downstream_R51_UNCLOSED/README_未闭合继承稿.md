# 后续四板：保留来源，不伪造已完成状态

`R51_UNCLOSED/B02~B05`是R5.1中对应板卡文件的继承副本。其原有针脚、网名、封装和功能占位尚未全部确认。`libraries`和`models`保持这些文件的相对路径。根工程名称仍标R51以避免与本批完成的原理图候选混淆。

## B02 ADC：下一优先级

基线保留AD9268并行CMOS、1.8V输出模式，而不是改称LVDS。附`engineering/AD9268_CMOS_pin_audit.csv`完整65焊盘映射（厂家裸露焊盘为0，文件中用65）及`electronics/libraries/AD9268_CMOS_Audited.kicad_sym`独立审核符号。该符号没有自动替换旧B02，因为旧时钟/转换器/抗混叠和I/O分配尚未闭合。

需要补齐：两路ADC输入FDA/抗混叠，AVDD/DRVDD去耦和基准，SENSE=GND的2Vpp模式，真实低抖动时钟MPN和驱动，SPI双向SDIO与输入电平转换，OEB/PDWN/SYNC上电状态，32数据+2DCO的源同步走线与Bank33=1.8V约束。不能从连接器针数推定所有针脚都空闲或都可做时钟输入。DCS开启时以不低于20MSPS验证；CMOS数据延迟按12采样周期起算，再对齐实际捕获和滤波延迟。必须读回寄存器并使用ADC测试码检查丢位/乱序/毛刺。

## B03 PMT电源与参考

H10720-20候选已集成高压，本板不是重新设计裸管千伏电源。需要真实+5PMT、±5AFE、0.5V偏置与0.5~1.1V控制发生器；加入独立限幅、上电默认、读回、滤波和故障顺序。不得逐像素改变VCONT后仍认定响应即时。厂家表格的增益调整稳定时间为指定条件下10s，不是10ms。

当前厂家PDF列出的-20阳极辐射灵敏度与早期项目文档不同。必须以实际订货型号、测量条件和原厂确认建立工作点，不能直接沿用旧光子预算系数。

## B04 24V分配和独立关光

原J1有逻辑针脚但无焊盘，先冻结实际连接器。需要输入保护、保险/限流、反接/浪涌、各支路DC/DC和低噪声后级、电源状态、独立关光通道和快门接口。激光模块实际使能电平/极性未定前，不能编造引脚。安全链的默认状态必须为禁止发光，不能靠FPGA软件“正常标志”作为唯一条件。不是已通过功能安全认证的电路。

## B05 运动与编码器

原TMC2209为29焊盘占位，没有完整逻辑针脚图。需确认实际封装、EP、供电、功率绕组、采样电阻、UART配置、限位及温升。TMC2209只作为牵引步进方向候选；高速polygon应保留OEM驱动总成，不用它直接代替polygon专用电机驱动。编码器实际输出（3.3V/5V/差分）与接收器尚待选型，不能把所有传感器直接接FPGA。

闭合顺序：先B06脉冲数据与B01工作点 → B02采集接口 → B03低噪声参考 → B04安全分配 → B05与真实电机/编码器。每一板均需完整原理图、正确针脚、布局/布线、ERC/DRC、台架证据后再发布。
