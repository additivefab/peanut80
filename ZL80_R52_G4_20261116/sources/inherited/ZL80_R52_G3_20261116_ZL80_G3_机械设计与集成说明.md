# ZL80_G3_机械设计与集成说明

本轮在G0/G1扫描接口和R5.1机械坐标基础上，深化四辊输送、轴系、提辊、机箱及板卡空间。这里的G3指机械输送工作包；不替代G2-E01的电路闭合。交付状态为 DESIGN_REVIEW_NOT_FOR_PRODUCTION。

| 用户交付项 | 实际文件 |
|---|---|
| 完整四辊STEP | 闭合、抬升5mm、爆炸三种总成；并附光机电上下文 |
| 采购与制造图 | 12项选型；23页图册；辊芯尺寸与工艺；基座及六平板DXF |
| 材料与公差 | 18组×3重复材料DOE；17项关键公差；5项片底间隙链 |
| 线束与验证 | 12条中心线路线；14项台架协议；计算模型、空白数据、分析程序 |

本包不是实机验收报告。新结构、采购包络、继承接口和未知细节分别标识；原厂孔位未确认的编码器底座、部分紧固件及提辊锁定件仍未冻结。

### 本轮必须审批的变更

基座由300×280×6改为300×288×6，保留电路板坐标，解决B04后排安装孔Y139靠近旧边缘的问题。四个脚位改为X±132、Y±120，避开B03安装孔。不能混用旧底板DXF。

联轴器由旧16mm长占位改为NBK候选总长30mm；电机前安装面改到X121.5。侧框由6mm改8mm，并添加轴承台阶孔、浮动槽、弹簧调节井及释放通道。详见CR01~CR11。

G2的新器件空间STEP另放sources/G2_reference，仅作对照。本次主总装沿用R5板框位姿。G2与R5的XZ板法向/元件面必须先做坐标转换核对，不能宣称所有新PCB元件均已清空。

## 01 继承接口与变更控制

当前采用入口测量随动下辊、出口主动牵引下辊，分别配编码器；两只上辊弹性压紧。只有一个走片执行电机，不是双电机张力伺服。外置放收卷负责低张力供给；扫描计量不能直接采用卷轴转速。

| 组件 | 具体实现 | 仍需关闭 |
|---|---|---|
| 入口下辊 | G3-R01轴总长189；左端接编码器 | 有效滚径、滑移和周期误差实测 |
| 出口下辊 | G3-R02轴总长196；右端接5/6联轴器 | 低速转矩纹波、驱动电流及温升 |
| 上辊×2 | G3-R03轴总长168；浮动块与M5锁定 | 锁紧方式、预载和释放操作评审 |
| 轴承×8 | 左端定位、右端游动；外圈压盖 | 样品配合、游隙、启动阻力 |
| 胶层 | 粘结/硫化后整辊磨削，Ø20成品 | 附着、迁移、掉屑、划伤DOE |
| 释放 | 两端同步提辊，名义行程5mm | 停驱动/禁光互锁、锁定件及人体操作 |

### 轴系尺寸不是一根直径6mm通轴

工作芯Ø14×100，两侧Ø7.4肩段、Ø6轴承位与不同轴端分开定义。左右轴承中心距144mm。左下辊夹紧轴环移动到X=-83.6，窄垫套伸至轴承端面；避免与轴承压盖和编码器安装板冲突。

上辊采用较小M5螺母和窄垫片，不再在上下20.2mm轴距内叠放两个带约20.8mm螺钉扫掠包络的轴环。CAD表示螺纹名义包络而非真实牙型。

### 供应商文件优先级

原厂具体料号图纸、样品与检验记录优先于通用CAD模型。NMB日文原厂页与美国页面的倒角字段存在转录差异，本轮取日文页0.15mm作审查依据，并保留供应商确认项。AMT机械图的精确孔位未完成视觉核验，因此自定义适配板孔不能冒充原厂孔。

完整12项选型表包含弹簧、胶料、基座、接触材料和未冻结的外置张力附件。无报价的项目保持RFQ，不写成0元，也不宣称现货。

## 03 电机、轴承与联轴器选型

必须把三个量分开：上辊法向夹紧力N、辊面可传递切向力μN、胶片纵向张力T。调压螺钉改变第一项，不能据此宣称第三项被闭环控制。

| 计算项 | 本版结果 | 前提 |
|---|---|---|
| 双弹簧合力 | 4.100 N/组 | 2×0.5N/mm×(18−13.9)mm |
| 上运动件自重 | 1.961 N/组 | 0.2kg是假设，须称重 |
| 总法向力估算 | 6.061 N/组 | 尚未含滑块摩擦及胶层压陷 |
| 摩擦牵引极限 | 1.818 N | μ=0.3假设 |
| 设计拉力/裕量 | 1.2 N / 1.515倍 | 目标2倍尚未满足 |
| 需2倍裕量时 | 8.0 N法向力 | 不允许未经划伤验证直接加压 |
| 转矩预算 | 0.015025Nm；系数3后0.045075Nm | 外部阻力0.003Nm、惯量等假设 |

上辊释放5mm时，弹簧工作长度由13.9变为8.9mm；采购压并长度要求不超过7.5mm仍需厂家确认。弹簧在STEP中是包络圆环，不是可计算疲劳与屈曲的实体弹簧。

保持转矩与所需转矩约3.11倍只作初筛。步进电机低速微步非线性、槽转矩、驱动限流、联轴器扭转及真实滚阻共同决定实际输送；通过台架后再决定是否换低纹波闭环驱动。

## 04 夹紧力、牵引力和动态裕量

物理基准A为基座上表面；B/C为主框圆销与菱形销定位特征。片面F=Z110是名义功能平面，不是可直接加工的基准面。每框一圆销一菱形销，避免两个圆销过约束强装。

| 对象 | 候选要求 | 检验与限制 |
|---|---|---|
| 基座 | 300×288×6，6061-T6；A平面0.05，局部0.02mm | 先消除加工应力，坐标测量；强度/热漂移未验证 |
| 轴承轴颈 | Ø6.000~6.004mm候选；Ra≤0.4μm | 先核准轴承配合和装配力，不能批量强压 |
| 外圈座 | Ø12.000~12.010mm候选 | 左端隙0.02~0.05；右浮动0.20~0.50待样品审 |
| 编码器/联轴器端 | Ø5.988~6.000mm | 夹紧区无涂层，满足两供应商实际公差 |
| 成品胶辊 | Ø20±0.010；轴承基准总跳动≤0.010mm候选 | 加载有效径另标定；几何尺寸不代表计量精度 |
| 两下辊 | 平行≤0.020mm/100mm建议 | 加载后验证，不用单件图替代装配测量 |

23页图册给出三种辊芯的分段尺寸、胶层处理与检验要求、底板40孔坐标、侧框及轴承/释放装配示意。没有完整标注的螺纹有效深度、倒角、定位销/锁定件与采购件细节须经DFM冻结，不应只凭STEP自动生成NC下单。

### 位置误差不是同一条尺寸链

AMT计数量化3.835μm、0.2°角精度等效34.91μm、联轴器变化转矩扭转约5.18μm、简支阶梯轴挠度约1.18μm来自不同定义。不能直接把它们当相互独立的高斯RMS值平方和。胶片滑移、有效径、跳动、编码器周期校准需分别实测，再建立系统位置预算。

## 06 片底间隙与误差链

本版选六块1.5mm 5052-H32平板＋独立角撑，均提供mm单位切割DXF。它是平板钣金方案，没有虚构折弯展开、K因子或折弯半径。若改为U形折弯件，需要另建折弯模型、回弹与装配接口。

基座40孔从实际CAD顶面完整圆孔提取；不以开边圆弧的质心当作孔心。螺纹仅用底孔/名义杆表示；切割图不能替代沉孔、精孔、攻牙工序。机箱载荷、提手可靠性、刚度、振动和漏光均未实测。

| 线束分组 | 空间与接口规则 |
|---|---|
| W01模拟 / W02数字 | 模拟对短线屏蔽；ADC数字接口电平与G2一致，J6真实位置待审 |
| W03/W04编码 | 5V CMOS经适当电平转换后入FPGA；远离电机相线 |
| W05/W06动力与数字电源 | 电机走后侧通道；SP2只接其规定5V，不接24V母线 |
| W07/W08弱光控制 | PMT控制与参考缓冲信号单独走线，远离PWM |
| W09/W10/W12同步及互锁 | SOS/EOS保留回流；激光/快门和释放互锁分别核对 |
| W11总电源 | 左侧24V口到B04保护输入，保留机壳端接与维护空间 |

12条路线是中心线和长度预算，不是已经通过柔性线束干涉或SI验证的成品线。插头外形、应力释放、维修拆出空间需实装；USB调试口可接近性列为强制检查项，吸取原机被ADC模块挡住的经验。

| 材料 | PU50A、后硫化硅胶50A、防静电PU50A |
