> 交付状态：文件已形成，可评审、试算和询价。G0冻结待签署；G1尚未通过台架验证；本包不是加工、投板或上板放行文件。

### 01 目标与范围

本包按用户确认的80 mm底片连续扫描需求建立工程输入：扫描方向预留100 mm；反射式旋转多面镜逐点横扫，胶片纵向连续平移；透射光进入横置矩形狭缝积分筒，由径向侧窗经PMMA导光件进入单PMT。[U01/U02]

G0交付需求、主参数、跨专业接口、候选零件、风险和冻结条件。G1交付扫描头预设计、扫描时序、名义多面镜几何追迹、理想光斑预算、接口CAD、供应商RFQ和PoC验证方案。真实镜头处方和供应商硬件尚未取得。

| 硬约束 / 当前候选 | 定义与边界 |
|---|---|
| 80 mm / 100 mm | 80 mm为有效成像宽度；100 mm是横扫预留，并不赋予100 mm胶片输送能力。 |
| 635 nm / 六面镜 | 635 nm为当前设计基线；六面镜为候选，不代表原机面数已实测。 |
| 50 um采样 | 首轮建议；不能直接宣称SRbD达到50 um或满足任何质量等级。 |
| 下游G2-G5 | 积分筒、PMT、走片、TIA/ADC和FPGA仅冻结必要接口，不在G1内冒充完整实现。 |

### 02 首轮评审应回答的问题

供应商能否同时满足100 mm物理扫描场、80 mm有效场、拟定光斑和低速工作点？实际镜头工作距离、入瞳和转子孔径是否适配现有布局？未关闭的答案不得由AI自动填写“通过”。

### 04 变更不可静默发生

若镜头或转子供应商要求更大尺寸，可提交变更单调整空间，但不能在保持旧图号的同时更换规格。80 mm有效幅宽和已确认架构不得由程序自动更改。候选面数、转速、焦距、束径、功率和板卡接口必须保留变更前后值及审批。

本包不承诺25 um实际分辨率、OD4.5性能、最终重量、最小外壳、EMC等级、激光安全等级、量产寿命和完整PCB性能。相关项目留待G2-G7分别形成证据。

## G0 统一坐标与机械接口

### 07 坐标定义

局部右手坐标：X为横向扫线方向，Y为连续进片方向，Z向上。局部原点在名义扫描线中心/片面。R5绝对坐标 = 局部坐标 + (0,0,110) mm。名义片面不等同于真实乳剂层焦面，后者需台架确定。[U03]

| 接口 | 名义值 / 重要限制 |
|---|---|
| 图像与像素 | ROI边界X=[-40,+40] mm；50 um时1600像素中心为-39.975…+39.975 mm。 |
| 同步及预留 | SOS/EOS目标±46 mm；扫描预留±50 mm；狭缝边界±52 mm。 |
| 镜面与镜组 | R5名义反射点全局(0,0,245)；镜组几何中心(0,0,210)，不是已知主平面。 |
| 焦距/工作距 | EFL=100 mm用于公式。WD、BFL、入瞳距离、机械基准面到像面距离均TBD。 |
| 镜组安装 | 本体96×44×30 mm旧包络；110×60×55 mm安装预算；焦距调节空间旧预算±15 mm。 |
| 同步折转件 | R5折转点Z=112，高于名义片面2 mm；真实触发点需投影标定。PCB中心不是光学触发坐标。 |
| 积分筒接口 | 筒轴沿X，顶部矩形狭缝，侧窗-Y；两端封闭。G1验证扫线不被片道/狭缝遮挡。 |

### 08 CAD交付状态

cad/parts中22个STEP来自R5.1包内实际文件。本包按26个原有装配实例重新组装扫描头与下游接口参考，没有凭效果图重画器件。每个几何体已进行有效性、体积和外廓读取；未执行完整干涉、公差或实际装配验证。

FreeCAD宏可按原始位姿建立对象树并保存FCStd审查工程，但当前环境未执行FreeCAD。此导入对象树不恢复原始参数化草图历史；它不能直接作为生产设计。

## G0 电气、时序与数据接口

### 09 只定义信号合同，不编造接线图

| 接口组 | 逻辑要求 | 尚待确认 |
|---|---|---|
| SOS / EOS | 硬件捕获边沿并保存时间戳 | 极性、电平、最小脉宽、比较器、线缆/缓冲 |
| INDEX / LOCK / FAULT | 面号有真实参考；丢index必须使facet_valid失效 | 主轴输出形式、Z脉冲位置、掉电行为 |
| LASER_HW_PERMIT | 默认关闭；独立硬禁能路径 | 激光器EN的电气规格、瞬态和安全回路 |
| SHUTTER反馈 | 失电闭合；反馈可诊断 | 驱动电压、开闭时间、失效模式 |
| 参考PD | ND之后取样，时间与PMT通道相关联 | 取样比、量程、模拟滤波与ADC输入 |
| ADC / 编码器 | 连续采样；保留样本时间与运动位置 | AD9268模式/延迟、SP2电平、CDC和计数方向 |

> EN_LASER不能等同ROI_VALID。SOS/EOS在80 mm图像区之外；如果仅在ROI内出光，同步探头可能永远收不到光。ADC时钟保持连续，有效性用数字掩码和质量标志表示。

### 10 样本/行元数据

至少保存config_hash、run_id、sample_time、line_id、facet_id、facet_valid、SOS/EOS时间、index_epoch、y_count、gain_id、reference_power和fault_flags。数据应能追溯至采样时刻，而非到达PC的时刻。

ADC数字管线延迟须按实际输出模式确定；采样标签须与该数字延迟匹配。AFE滤波/群延迟应独立测量和补偿，不能直接假定为整数个ADC时钟。

信号表只给逻辑名称，不宣称3.3V、1.8V、5V或24V可互连。最终针脚、方向、电平和上电状态要在G4/G5签署后才允许接线。

## G0 候选零件与风险关闭

### 11 采购和自制边界

主轴、精密多面镜、驱动和防护优先作为供应商扫描器总成采购。激光、整形、ND、快门、f-theta和同步探测应联合询价，而不是按单一焦距或转速分别下单。[U02/V01/V02]

| 关键候选 | 为何尚不能冻结 |
|---|---|
| 635nm激光/APC | 型号、束径、M2、椭圆率、工作点与EN恢复时间未取得。旧φ12×50仅空间预算。 |
| 六面polygon | 旧外接圆半径20 mm和5 mm束在+50 mm端出现1/e2轮廓负余量。需口径/束径/入射角联合选型。 |
| f-theta镜头 | EFL100不是工作距离。必须同时取得真实全场性能、入瞳距离、机械图和可复核模型。 |
| S5971 SOS/EOS | 仅PD候选。厂家100 MHz规格有偏置条件，不等于整条探测链达到79.58 ns抖动目标。[V03] |
| PMT与收光 | H10720-20是G2候选，本版不设计新的高压模块或宣称收光效率。 |
| 底座/支架/板框 | 继承名义几何，完整紧固、加工基准、公差、线束及检修空间仍需详细化。 |

### 12 P0关闭顺序

优先关闭R01镜面截光、R02镜头处方、R04低速稳定性和R05同步照明窗口。R03器件身份、R06绝对面号与R09弱光性能必须在对应关口单独通过。13项风险的责任角色、下一动作和证据要求见risks_and_actions.csv。

本包没有把任何候选型号视为已采购合格，没有使用同系列宣传范围代替选定型号规格，也不提供加工转子的尺寸批准。
