# ZL80 G5工程规则
保留635nm、polygon、80mm有效幅宽、100mm光学预留、单PMT链路；不要改成相机或振镜。
只修改经任务批准的源文件，保留来源和变更记录。不要把旧引脚表/型号当实物证据。
Python模型、HDL仿真、Vivado综合、布局布线、实机验证必须分别记录。
禁止将epoch_verified、时戳有效或制造批准固定为真来绕过门禁。
不要生成bitstream、烧录、启用激光或驱动电机；这些需要后续硬件审批。
所有RAW读写不得隐式裁剪0/65535或填补缺口。修改协议必须升级版本并同步测试。
绝对facet必须由实际索引和相位映射确定；相对行号不得冒充绝对镜面号。
