# ZL80 ADF50-V0.1 重力辅助自动馈片一体化方案
2026-11-16｜初步设计，不是制造放行。

INTEGRATED FILM HANDLING / 2026-11-16

建议基线：近立式重力片仓 + 托挡承重 + 前张剥离 + 可调反向分离辊 + 双面除静电 + 整张验证缓冲 + 原四辊扫描运输改造 + 独立收片。

重力用于整叠落底定位和逐张下行助力，不让50张同时自由下落。所有扫描必须在整张单片确认、馈片压辊释放和测量链稳定后启动。

本版保留现有635nm旋转棱镜、80mm有效宽/100mm扫描预留、积分筒—亚克力收光—PMT链路，不重选光学或模拟前端。

已给：系统/力学/空间/控制接口、参数预算、验证矩阵和参考状态机。未给：生产级托趾剥离机构、完整B10电路/布线、实测摩擦/静电/分片率及整机安全结论。


## 01 需求边界与来源

用户要求：一次装入50张80×300mm底片，自动逐张扫描并收片；供片利用重力，同时考虑静电与摩擦力。默认片子已经显影、定影并完全干燥；不混装衬纸、保护袋、胶带或订书钉。

| 项目 | 本版定义 | 状态 |
| --- | --- | --- |
| 批次 | 50张；有效文件50份、实物确认收片50张 | 用户目标，不是已达到的可靠性 |
| 介质 | 80×300mm；片厚0.20mm算例，0.15–0.35mm试验范围 | 除长宽/张数外均待实测 |
| 批次一致性 | 首轮同一材料结构、同一片厚等级 | 混厚批次不放行 |
| 表面 | 两面都按需保护的乳剂/影像面考虑 | 不假设存在可损伤的空白边 |
| 检测链 | 前沿/双张/全长/偏斜/交接/收片/静电诊断 | 不能用单一透射亮度判双张 |
| 工作尺寸 | 约350宽×1100深×550高mm的展开空间预算 | 未做完整装配CAD与干涉验证 |

### 项目资料支持什么

原始《扫描仪自动馈片装置调研学习》记录了窄缝限张方案失败，建议沿用斜立式结构并使压板压力在不同片数下基本一致；PU/硅胶作为多规格测试件，胶料污染风险需验证。[U1]

项目PPT第17–22页提出斜立堆叠、近恒力压板、拾取/分离辊、多源双张检测，并要求分片与扫描计量解耦。[U2] 本版增加50张/300mm完整缓冲、载荷分配、扫描首尾接管和批次账本。这些新增内容是本次设计，不是原机已验证事实。


## 02 重力供片：托挡承重，不让片堆下冲

片仓相对水平80°为首轮起点，可调75–85°。长边沿坡向，所有底片下缘靠在圆角托趾/保持闸上；一侧固定基准、另一侧轻压可调导轨。前张抽取时，其余片堆始终有独立支撑。入口不采用只容纳一张厚度的硬缝。

### 重量与法向力算例

假设厚度0.20mm、等效密度1400kg/m³：单张质量6.72g，50张336g；片堆名义厚10mm。若片厚为0.15–0.35mm，50张厚度为7.5–17.5mm。片仓给35mm叠厚空间，用于公差、翘曲与后随动结构；这不是允许随意超装的容量。

| 量 | 80°、50张算例 | 意义 |
| --- | --- | --- |
| 整叠沿坡重力 | 约3.25N | 必须由托挡承担，不能全压到分离辊 |
| 整叠法向分力 | 约0.572N | 引起片间接触压力 |
| 仅剩1张法向分力 | 约0.011N | 固定附加弹簧力不等于总压力恒定 |
| 总接触力目标0.9N时 | 满仓附加约0.328N；末张约0.889N | 用测力/随动配方补偿，具体力待DOE |
| 托挡静载预算 | 15N | 按厚片和裕量起算，最终仍需强度与断电试验 |
关键纠正：恒力弹簧只保持它自己施加的附加力，并不能自动消除片堆重量的法向分量。本版建议0–5N量程的测力试验通道，先验证总接触力，再决定采用闭环跟随还是经过标定的机械补偿。

还必须检查配方可实现性：若50张全部厚0.35mm，80°时自然法向分力约1.00N，已高于0.9N目标；仅靠正向压板无法降低它。此时要改为更陡角度、卸载结构或更高且已验证的接触力配方。75°厚片满仓可能超过1.2N试验上限，禁止盲目执行所有DOE组合。

### 断电与保持

断电、开盖、卡片时，托挡/保持闸应保持防坠状态，拾取停止。任何状态转换不得让两道支撑同时撤走，使50张失控落入片道。托趾承重和前张剥离界面是G2/G3之前的机械关键样件，不把本页功能图当成已完成的机构。


## 03 前张剥离与反向分离力窗口

动作顺序：托挡保持剩余片 → 除静电并从层间边缘松片 → 前张在受控导向靴处局部剥离 → 两段同轴拾取辊向下送片 → 低转矩反向辊抑制第二张 → 检测站确认 → 整张进入缓冲区后，分离辊与拾取辊完全释放。

前张法向抬离1–3mm仅为试验调节范围，用来跨过托边/形成空气间隙。不要用金属刀片强插两层底片。如何可靠剥离而不损伤乳剂必须用透明工装验证；若滚动剥离没有稳定窗口，保留小型真空助剥作为替换模块，不直接提高压力硬拉。

### 分离条件：必须同时存在上界和下界

设Fp为最小可用拾取切向力，F12为最差片间摩擦，Fa为剩余粘附力，Fpath为路径阻力，G为单张沿坡重力，Fr为有效反向分离力。在其余片堆已被托挡支撑的前提下：

F12 + Fa + G < Fr < Fp + G − Fpath

Fr还受到反向辊胶面摩擦上限限制，不能仅由电机设定电流推算。需要实测输出轴端小转矩、低速纹波及离合器滞回。

| 算例项 | 数值 | 状态 |
| --- | --- | --- |
| Fp / F12 / Fa / Fpath | 0.8 / 0.2 / 0.05 / 0.1 N | 全部为示例假设 |
| G | 约0.065N | 由0.2mm单张重量计算 |
| Fr允许窗口 | 约0.315–0.765N | 不含额外安全裕量 |
| Fr示例选点 | 0.45N | 不是量产设定 |
| 半径10mm时轴端转矩 | 4.5mN·m = 0.0045N·m | 不能误写成4.5N·m |
当Fa升至约0.50N，这个示例窗口收缩到零附近；继续加压可能同时增加片间摩擦、刮擦和卡片。正确顺序是先除电、打开层间空气、减少堆载耦合，再调法向力和分离转矩。


## 04 静电、摩擦、材料与气流控制

### 不能只靠金属接地或防静电胶带

接地对导体有效，但不能保证绝缘胶片上的电荷迁移到地；离子化能中和绝缘表面。环境湿度会影响充电和保持，但提高湿度不是可靠的单一消电方法。[E1] 原调研提到防静电胶布作为早期尝试，本版不把它视为已经解决了片间静电。[U1]

### 离子化位置与开口

设置入口/前张外表面和下口层间剥离区两处可调离子化；先产生微小空气间隙，再让离子气流进入暴露的两面。仅对整叠外表面吹风，不能假定已中和埋在内部的49个界面。片子分离后还需防止与导轨/胶辊摩擦再次带电。

SMC IZN10E等商业24V喷嘴离子器可作为台架候选，但需要按原厂气源、接地、安装、诊断和维护条件使用。[E3/E4] 不自制开放式高压针。设置气流/压力、故障、污染诊断，并用场强计或标准化电位测量在规定距离验证前后差值。

### 与PMT测量隔离

离子高压、风机、剥离气流和驱动脉冲在预处理阶段工作；扫描前关断/静默并等待实际测得的稳定时间，确认模拟参考恢复。后续只有通过暗场、平场、条纹和噪声对照，才能考虑边扫描边预处理下一张。

气流从片仓向独立过滤/排风路径走，避免把尘粒吹到积分筒、亚克力收光板或PMT。离子化舱需要适当通风，不能兼作不通风的密闭光学舱；臭氧、气源污染、维护与接地按厂家要求和整机评估处理。[E4]

### 材料与试验

原资料提出PU作为试验胶料、硅胶经合适后处理降低污染风险；本版保留为候选而非确认寿命优势。[U1/U2] 首轮不做深网纹、不喷涂防静电液、不添加未经资格确认的填料；以真实底片两面的划伤、残留、掉屑、摩擦稳定和老化数据决定胶料。

20–30%、40–50%、60–65%RH只作为建议的环境试验档，且必须在胶片制造商允许条件内。不能直接向乳剂喷雾；高湿也可能增加粘连。


## 05 整张双张验证与缓冲段

一张底片的前沿通过检测，不等于尾部也没有重叠。300mm长片必须完整通过最终双张检测站，再允许正式扫描。首版采用整张缓冲，而不是把“分片成功”的瞬时信号直接交给扫描主机。

| 接口 | 名义坐标/长度 | 说明 |
| --- | --- | --- |
| 扫描线 | Y=0；Z=110mm | 继承前文讨论值，待现机确认 |
| 最终双张检测站 | Y=-390mm | 全片经过，累计质量标记 |
| 停片前沿 | Y=-35mm | 入口计量辊Y=-42可先夹持 |
| 停片尾沿 | Y=-335mm | 300mm片全长已过双张站55mm |
| DS站至停片前沿 | 355mm | 至少片长+检测/制动行程+裕量 |
| 缓冲夹持点 | Y=-300/-180/-75mm起点 | 扫描接管后所有压辊/离合需释放 |
停止预算：d = vτ + v²/(2a) + δ。以v=150mm/s、τ=30ms、a=750mm/s²、裕量δ=10mm计算，d=29.5mm；需要路径至少329.5mm，本版355mm剩25.5mm预算余量。打滑、传感器去抖延迟增加等会使预算失效，必须实测最坏情况。

从80°片仓转入水平段暂按R60mm导向试验件，转弯路径约83.8mm。0.2mm片的薄片弯曲外表面应变估计t/(2R)≈0.167%，厚0.35mm时≈0.292%；这不是乳剂层或旧片允许应变，需要卷曲/老化/干湿条件验证。

### 双张与偏斜检测

超声双张作为主候选，辅以独立厚度或第二物理原理。microsonic官方资料说明塑料薄片的安装角和参数依材料而变；必须用真实单张/紧贴双张/错边/高低OD片验证，不能把商品的通用“即插即用”宣传当成适用性证据。[E2] 两位置超声检测时应按厂家触发策略避免串扰。

透射光电仅辅助前沿/偏斜/存在检测，不单独判双张。首轮同一材料/厚度配方，否则0.35mm单张与0.15mm双张的厚度阈值可能重叠。


## 06 与现有四辊扫描链的关键改动

按之前讨论的辊站Y=-42/+42mm：前沿到达扫描线时，尚未进入+42mm出口辊。因此不能继续用“入口仅被动、出口唯一驱动”，又同时要求馈片在扫描前完全释放。必须补一个受控的入口扫描驱动或等效计量牵引。

| 片段 | 主运动来源 | 交接规则 |
| --- | --- | --- |
| 前沿进入扫描至出口辊咬合前 | 入口下辊主动、入口计量反馈 | 缓冲提前放行并卸载；扫描速度在前沿到线前稳定 |
| 胶片同时跨过两辊站 | 一主一从；另一驱动限矩/同步 | 不能两电机硬顶速度；中段有重叠长度用于平滑切主从 |
| 尾沿离入口辊后 | 出口下辊主动、出口计量反馈 | 切换计量基准需要共同标定，避免图像Y坐标跳变 |
| 片尾离开扫描及出口辊后 | 收片运输接管 | 只有尾沿越过出口辊并确认隔离，才允许快速出片 |
不能把前42mm或后42mm简单裁掉后仍报告全300mm扫描。入口与出口轴编码器是候选反馈，需用标定靶证明胶片真实位移与两段坐标接续；两轮同速并不能排除两轮共同打滑。

### 真正解耦，而不是“电机停了就算释放”

分片辊、反向辊和缓冲辊必须具备抬起/离合/低阻释放机构，并有位置确认。主机收到full_sheet_single、input_nip_engaged、all_feeder_released和analog_settled后才允许扫描。夹着胶片但电机停转，仍会产生摩擦与齿轮箱反拖，不能通过验收。

收片托盘同样不能通过胶片自重或辊速差牵拉扫描区。尾沿超过+42mm出口计量辊后，再以+65mm作为首轮安全接管参考，允许收片运输加速和低落差堆叠。最终边界需加速度/打滑和真实片长验证。


## 07 B10自动馈片控制与G2/G3接口

建议新增B10作为自动馈片控制板，分片状态机由本地控制器执行，FPGA保留扫描计量与硬件时间戳。不是把几十根24V传感器线直接接到SP2排针。B10和主机用隔离CAN或RS485握手；紧急关断及激光安全继续使用独立硬件链。

| 功能组 | 传感/执行 | 设计要求 |
| --- | --- | --- |
| 片仓 | 有片、近空、总法向力、托挡位置 | 片厚/重量只能估余量，不能精确数张 |
| 分离 | 拾取电机、限矩反向辊、抬起机构 | 小转矩真实测量与限幅，断电防整叠落片 |
| 静电/气源 | 离子器READY/ALARM、气流/压力、温湿度 | 故障阻止上片；诊断不代替实测消电效果 |
| 缓冲/定位 | 双张两位置、厚度复核、前沿/尾沿、偏斜 | 全程质量位与长度验证；上游所有压辊释放回读 |
| 扫描交接 | 入口/出口驱动状态与编码器 | 需修改B05或增加独立驱动通道 |
| 收片 | 尾沿隔离、到达、满仓/高度 | 物理收片确认与文件成功分开计数 |
### B10空间预算与PCB约束

建议板框110×80×1.6mm，4层；正面器件高18mm、背面净空5mm、连接器插拔及线束端部至少30mm作为起算。力传感模拟前端、工业输入保护和电机热区分区；24V输入不能直接进入3.3V逻辑。驱动器数量、电源峰值、热与真实连接器未冻结。

本包交付的是B10功能与空间接口、I/O清单和状态机参考，并没有生成已完成的B10原理图或布线文件。G2要先完成传感/隔离/驱动/电源的真实器件级设计；G3再做叠层、回流路径、ERC/DRC、原理图一致性和整机回装。

本地位置反馈、传感器滤波、制动响应和断线故障均需定义最坏时延，不能靠通信“通常很快”批准355mm缓冲。


## 08 50张批次状态机与异常恢复

正常顺序：IDLE → NEUTRALIZE → SEPARATE → QUALIFY → PARK → HANDOFF → SCAN → EJECT → COMMIT；成功达到50且无未决项后进入DONE。首版不在本张扫描期间预拾下一张，先关闭静电/驱动噪声与张力耦合风险。

| 异常 | 处理 | 计数/数据 |
| --- | --- | --- |
| 双张或尾部重叠 | 尚未扫描且安全时退回、重除电、重试 | 同一候选任务，完成数不增 |
| 偏斜超限 | 低速预定位；超出可纠正范围暂停 | 不把有误坐标当正常Raw |
| 卡片/释放未到位 | 关光，受控停机并防坠片 | 记录位置/传感器，待人工恢复 |
| 2次自动重试耗尽 | HOLD；保留批次和片序 | 不跳过底片并宣称50完成 |
| 物理退片数量不明 | 隔离暂存并要求重新清点 | 双张捆包不能简单记reject=1 |
| 文件成功但收片未确认 | HOLD或安全收片恢复 | 扫描成功与交付完成不混同 |
| 断电恢复 | 重核片道中实物与最后提交任务 | 禁止自动从“上一张+1”盲目续扫 |
完成标准是：50个唯一有效图像文件已持久保存，50张实物收片确认，片仓/缓冲中没有未决片，计数与装入数量核对。每张保留Job ID、Attempt ID、配方、厚度/双张记录、扫描标定版本和错误历史。

出片堆叠会使最后一张位于最上方，物理顺序可能与装入顺序相反；在任务清单中明确对应关系，不以肉眼叠放顺序替代身份确认。首轮只接受已知顺序/同厚度批次，处理胶片上的已有标签不得遮挡影像或掉胶。

control/batch_reference.py是无硬件访问的参考状态机；29项Python测试检查计数、交接门槛和故障不放行，不是可下载到设备的安全固件，也不代表分片成功率。


## 09 节拍、可靠性与试验路线

首版串行批处理预算采用每张慢速运输400mm（300mm片长+35mm前导+65mm尾部隔离），每张除电/拾取/定位/收片辅助时间暂按5秒。以下只是节拍模型，不是已有设备实测。

| 扫描速度 | 50张仅片面扫描 | 含首尾与辅助预算 |
| --- | --- | --- |
| 15mm/s | 16.7分钟 | 约26.4分钟 |
| 5mm/s | 50.0分钟 | 约70.8分钟 |
| 1.5mm/s | 166.7分钟 | 约226.4分钟 |
高OD模式的实际扫描速度由现有光电系统决定，不能为了“50张快扫”擅自提高主扫描速度。辅助时间、预送料速度和离子化时间需通过样机测得后替换。

### 从单张成功率到50张整批成功率

在独立、同分布的理想假设下，批次成功率=P单张^50。即便单张成功率99.5%，50张不发生中断的概率也只有约77.8%；单张99.9%对应约95.1%。要把50张整批99%作为目标，最终单张成功率需约99.9799%。湿度、磨损和污染会导致相关失效，实际验证必须按这些条件分层。

零失效的有限试验不证明“永不失效”。作为统计数量级，若15000次代表性且近似独立试验无失效，单次失效率的95%单侧上界约0.000200；反复扫描一组容易的片材不能替代这种样本覆盖。

### 试验顺序

① 真实片材厚度/质量/摩擦/剥离力、静电与材料污染基线；② 透明片仓与托趾/剥离试样，50/25/10/1片及断电防坠；③ 双张传感器完整故障库；④ 300mm全长缓冲与停止距离；⑤ 扫描入口/出口首尾接管及静默噪声；⑥ 50张完整批次、收片和断电恢复；⑦ 分环境、老化辊和标准化污染的长期验证。

每阶段同时记录漏检双张、漏送、重试、卡片、偏斜、划伤、粉尘/残留及图像质量，不只统计“能送出去”。详细试验因子见engineering/DOE_plan.csv。
