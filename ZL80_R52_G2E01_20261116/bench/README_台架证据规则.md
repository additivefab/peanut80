# 台架：本次没有任何实测结果

`test_matrix.csv`定义14项建议试验；`execution_records_TEMPLATE.csv`全部为NOT_RUN，测量值为空；`sync_timing_TEMPLATE.csv`用于采集前后沿原始时间戳。它们是执行协议，不是证据本身。

先做无激光、无PMT、无开发板的低压限流检查，再做等效电流输入。未知极性、接口电平、接地或引脚方向时停止接线。不得把信号发生器的50欧输出直接接PMT求和节点，不得用通用探头长地线挂在高阻输入。插入实际PMT之前必须确认+5V、控制范围、限流、针脚/插座方向、遮光和过载风险。

真实激光试验必须在原有遮光与硬件互锁有效条件下进行；本包不提供绕过互锁的办法。故障注入先在电流/电气等效台架进行。

每次实测至少记录：板号/序列号、原理图/PCB修订及SHA256、BOM实装差异、仪器与校准、接线照片、供电和负载设置、环境、原始示波器/逻辑分析文件、分析代码版本、判定规则与复核人。仅截图不能替代完整Raw波形；模型CSV不能作为实测CSV。

B06同步测量中，固定幅度重复测得的RMS抖动与改变光强后的确定性时间偏移必须分别报告。前后沿平均能减小本包对称测试脉冲的偏移，不证明真实遮光/散射/失焦脉冲具有同样效果。遇到漏脉冲、多脉冲、非对称或启动瞬态时要保存异常，不得只选择“好看”的边沿。

B01不同增益档是焊接配置方案，不是在线高速自动切换。1k跨阻达到1V需要1mA；这不适合直接套用到厂家给定最大平均电流100uA的PMT模块。100uA也不是任何条件下的线性保证，应保留余量并实测。
