# FPGA参考边界

R5.2 的归一化采集核心、候选前端、接口约束和仿真入口见 [G5 工程包](../ZL80_R52_G5_HF_20261117/README_先读.md)。主设计采用 A 路主 TIA、B 路 ×32 高增益和 B08 独立慢速参考 ADC，接入边界及复核见 [融合设计基线第 8 节](../docs/ZL80_R52_融合评估与设计基线.md)。以下为 R5-PDR1 的标签和计数参考。

SystemVerilog仅为标签延迟及AB计数逻辑起点。Python单测不是RTL仿真；本环境未运行RTL编译、综合、时序分析或上板。

AD9268连续20MSPS，DCOA/B均作为源同步捕获时钟，先对齐每通道后进入共同采样序列；跨域必须设计可靠FIFO/握手。SOS/EOS与编码器应由同一硬件时基锁存，异步边沿的同步延迟、量化误差和抖动要校准。不能简单声称所有外部信号天然同步。

在ADC采样边沿为输入光学事件生成标签。ADC本身已有12周期流水线，数据另有数字延迟D；标签对应总延迟12+D。不再把ADC数据重复延迟12周期。实际12周期相位用固定标记波形验证。

硬件激光禁能不由本RTL独占控制，应独立硬件覆盖开盖、快门、失扫、过温与看门狗。上电默认关光。不要门控ADC采样时钟；使用有效标志。

XDC是V1.3B引脚分配草案；原理图版本、Vadj=1.8V、5V缓冲与ADC控制1.8V电平必须实物核对。文件没有完整IO延迟、时钟域策略或板级偏斜约束。
